# Hawkeye v1.9 — панель управления, настройки и статистика

Версия для L2Meta Interlude на планшете KVADRA_T / Android API 32.

## Настройки перед запуском

Параметры на стартовом экране (сохраняются локально и читаются при каждом новом ручном запуске):

| Вариант | Допустимые значения | Защита |
|---|---|---|
| Длительность | 1, 3, 5, 10 минут | После лимита только PAUSED |
| Интервал касаний | 3,5 / 5 / 7 / 10 секунд | Не менее 3,5 секунды |
| Предельное число жестов | 4 / 12 / 20 / 40 соответственно | При исчерпании только PAUSED |

Никакого бесконечного режима и изменения кнопок/координат по неподтверждённому изображению.

## Живой экран

- Верхняя панель: статус захвата, состояние автоматического боя, жесты и защита.
- Статистика: длительность сессии, подтверждённые цели, успешные касания выбора цели и атаки, события снижения HP.
- Кнопки ПУСК / СТОП / ручной тест и настройка отображения поверх других окон.
- Подробная диагностика, сохранённые PNG и истории ниже в прокручиваемом блоке.
- После PAUSED/STOP время сессии замораживается; показатели не подменяются заявленными «убийствами» (исчезновение панели цели не доказывает гибель моба).

## Остановка поверх игры

Для компактного плавающего красного **«■ СТОП»** требуется Android-разрешение **«Поверх других приложений»**. Его пользователь разрешает самостоятельно через кнопку в Hawkeye; приложение не включает его без согласия.

При активном автобое сервис показывает кнопку у правого края на средней высоте экрана. Нажатие немедленно выключает дальнейшие автожесты и убирает кнопку. Если системные настройки KVADRA запрещают оверлей, всё продолжает работать без него: остановка доступна из уведомления службы или из приложения.

## Что осталось проверить на устройстве

1. Установить v1.9, убедиться, что настройки отображаются и сохраняются.
2. Разрешить отображение поверх других окон только если требуется плавающий стоп.
3. Выбрать **1 минуту** и **5 секунд** для короткого первого теста, затем запустить наблюдение и автобой.
4. Проверить, что в игре присутствует красная кнопка «СТОП», а в Hawkeye верно обновляются счётчики.
5. Проверить остановку по времени, по кнопке и в уведомлении; убедиться, что после остановки новых жестов нет.
6. После успешного теста можно пробовать 3–10 минут, сохраняя все защитные паузы.

Постоянная автоатака в фоне без ограничения времени **не реализована**. Разрешение на оверлей не влияет на работу MediaProjection и AccessibilityService.
