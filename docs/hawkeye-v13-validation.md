## Проверка
1. Установить APK из ветки feature/hawkeye-v13-bar-diagnostics.
2. Запустить захват полного экрана и открыть L2Meta.
3. На кадрах с игровым HUD сравнить значения cp/hp/mp/target с визуальными показателями.
4. Вычислить абсолютную погрешность в процентных пунктах; цель — не более 3 п.п. на каждой полосе.
5. Проверить кадры без цели, с пустой полосой цели, при изменении HP и при смене разрешения.
6. Проверить, что наблюдатель не выполняет касания по игре.

Изменение v1.3: детектор учитывает наиболее длинный непрерывный цветной участок, начинающийся около левого края полосы, вместо последнего цветного пикселя. В журнал добавлен confidence (доля длины этого участка в длине полосы). Это эвристика, а не статистически калиброванная вероятность.

**Важно:** эталонный PNG пока не встроен в автоматический тест. Не считать точность подтверждённой до прогона на устройстве и сравнения с эталоном.
