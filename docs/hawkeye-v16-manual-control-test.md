# Hawkeye v1.6 — одиночный тест кнопок «Цель» и «Атака»

На двух вариантах интерфейса L2Meta координаты отличаются. Детектор подтверждает **обе** формы одновременно: голубую прямоугольную рамку «Цель» и красную круглую «Атака». Если одна из форм не определилась, координаты не придумываются и касание не выполняется.

| Интерфейс | Цель (центр, 2000×1110) | Атака (центр, 2000×1110) |
|---|---:|---:|
| Классический (7 игровых PNG) | ≈ (1687, 754) | ≈ (1859, 861) |
| Круговая раскладка (2 PNG) | ≈ (1709, 1062) | ≈ (1815, 947) |

Значения рассчитаны по предоставленным изображениям, **не** являются постоянными координатами касаний: приложение распознаёт и пересчитывает их заново на каждом кадре.

## Как проверить на Pretech 1102 / KVADRA OS

1. Установить отладочный APK v1.6; включить AccessibilityService L2 KVADRA Test.
2. Нажать **«Начать наблюдение»** и дать доступ к полному экрану.
3. Открыть L2Meta и проверить, что в диагностике появилась раскладка `controls=CLASSIC` или `controls=RADIAL` и обе координаты.
4. Для теста «Цель»: **снять выделение противника** в игре, вернуться в Hawkeye, нажать **«7. ОДНО тестовое касание „Цель“»** и в течение 20 секунд снова открыть игру. Касание возможно только в состоянии SEARCH.
5. Для теста «Атака»: выбрать живого противника, добиться состояния ATTACK, вернуться в Hawkeye, нажать **«8. ОДНО тестовое касание „Атака“»** и открыть игру.
6. Проверить в Hawkeye статус «Тест кнопок». Жест `onCompleted` не доказывает удар или смену цели: наблюдайте игровой экран и изменения панели выбранного противника.
7. Кнопка **«9. Отменить тестовое касание»** удаляет отложенный запрос. Остановка наблюдения также отменяет запрос.

## Ограничения безопасности

- Никакого непрерывного автофарма: **не более одного жеста на одно явное действие пользователя**.
- Касание не выполняется, пока виден интерфейс Hawkeye вместо игрового экрана.
- Запрос касания истекает через 20 секунд.
- Нет запасных координат при нераспознанной раскладке.
- Обычная «Атака» тестируется только при `ATTACK` с подтверждённой выбранной целью.
- Выбор «Цель» тестируется только при `SEARCH`, когда панель выбранной цели отсутствует.
- Проверка на реальном планшете и в двух раскладках ещё требуется; результаты GitHub CI не подтверждают работу AccessibilityService в игре.
